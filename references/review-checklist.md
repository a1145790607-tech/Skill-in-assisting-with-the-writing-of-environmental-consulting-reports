# 报告审校清单

按本次任务选择检查项，调查介绍不强制使用分析与措施项。

## 范围与结构
- [ ] 当前小节服务研究目的，保留用户已认可的术语、结构和详略。
- [ ] 已识别不同对象及同一对象不同方面的并列关系，跨句、跨段、跨条目检查对应顺序。
- [ ] 共用条件明确适用对象；独有信息留在相应位置；先后或因果关系未被误套成并列。
- [ ] 父子、同级和跨章没有无效重复，必要接口与直接比较仍清楚。

## 依据与数值
- [ ] 文件名称、已定义简称、许可证或报告编号、监测时段及关键数据保留且匹配。
- [ ] 现状、预测、规划、设计和实测口径明确，未把建议或计划写成已完成事实。
- [ ] 单位、时间、空间、统计量、系数与附加比例一致；子项、合计和包含关系清楚。
- [ ] 未声称核对未读取的文件，未补造数据、标准、设施或合规状态。
- [ ] 已发现的实质错误按材料修正并说明依据；无法消解的数据冲突已具体指出，未擅选数值。

## 分析与结论（适用时）
- [ ] 判断有标准、基准或对照；阈值有来源，描述性分组未冒充控制限值。
- [ ] 合规判断具备要求、项目事实、明确比较；标准和对象及适用情景匹配，版本、评价时点及过渡期已核对或明确待核；排放、质量、许可及内部控制要求未混用。
- [ ] 多指标结果没有选择性只报有利项；可量化的影响范围、时长或受体已交代。
- [ ] 归因有依据，结论回答当前问题，重要不确定性和不利发现未删去。
- [ ] 未为调查介绍擅加分析结论，未在分析段机械追加措施。

## 图文与语言
- [ ] 表格采用可比的共同维度，长段说明和独有参数留在正文。
- [ ] 图表和文字分工清楚，文字保留关键关系而非逐值抄写。
- [ ] 没有常规口号式开合、防御性长段或无依据的“合理、可控”等判断。
- [ ] 精简压缩表达而未损失必要依据与技术含义；并列整齐未以删信息实现。

## 措施与专家回复（适用时）
- [ ] 措施有对象、行动、适用触发条件、责任及效果核查，资料缺项未虚构。
- [ ] 重要问题在报告内有实际处理去向，监测未被当作问题已解决。
- [ ] 专家回复交代修改依据、具体内容与位置，未只写“已采纳”。
